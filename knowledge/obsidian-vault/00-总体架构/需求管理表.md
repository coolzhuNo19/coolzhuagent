# 总体架构需求管理表

## 需求管理表

| REQ/主题 | 状态 | 迁移摘要 |
| --- | --- | --- |
| 会话配置和真实会话链路 | PASS/持续回归 | 真实模型流式回复、上下文装配、workspace 隔离。 |
| 工具真实调用 | PASS/持续回归 | read/glob/write/授权 PowerShell/WebSearch/多 tool_use。 |
| Computer Use 工具化真实调用 | PASS/CHECK | 接口、权限、浏览器准备通过，真实键鼠需人工录屏确认。 |
| 多 Agent 协同与 Goal 长程任务 | PASS/部分待场景 | API 级最小协同、角色配置、phase、dispatch/status/cancel。 |
| 打包/加密/完整性 | 冻结 | 保留方案，不进入当前实现队列。 |

## 状态口径

| 状态 | 定义 |
| --- | --- |
| 已完成 | 已实现并通过基础验证。 |
| 测试中 | 代码已完成，仍需自动化、矩阵或真实交互验证。 |
| 待交互验证 | 方案或代码就绪，剩余真实窗口/硬件/人工确认。 |
| 开发中 | 已开始实现，仍有功能缺口。 |
| 待开发 | 需求确认但尚未实现。 |
| 冻结 | 当前不实现，只保留方案和风险记录。 |

## 更新规则

- 新需求先入需求表，再补方案、实现、验证、work-log 和状态回写。
- 需求状态不得只停留在口头计划；验证不充分时使用“测试中/待交互验证”。
