# 总体架构原理流程图

## 原理流程图

```mermaid
flowchart TD
  User[用户] --> GUI[gui-web 主控制台]
  GUI --> Desktop[gui-desktop 桌宠/Tauri shell]
  GUI --> Core[core-runtime 会话/上下文/权限]
  Core --> LLM[llm-adapter Provider/stream/tool_use]
  Core --> Tooling[tooling registry/plugin/MCP]
  Tooling --> CU[computer-use 输入执行]
  CU --> Vision[vision grounding/verify]
  Vision --> GUI
  Core --> Diag[diagnostics trace/log/health]
  CLI[cli] --> Core
  MCP[obsidian-mcp 等 MCP servers] --> Tooling
```

## 迁移摘要

- 主线从 Web GUI 进入 core-runtime，再按需调用 LLM、工具、视觉、Computer Use。
- Desktop 是用户可见壳与桌宠反馈，不应承载核心业务。
- Diagnostics 贯穿所有模块，提供 health、trace/span 和日志窗口。
