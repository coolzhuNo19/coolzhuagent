# Vision 原理流程图

## 原理流程图

```mermaid
flowchart TD
  Capture[桌面/窗口/附件截图] --> Request[VisionRequest]
  Request --> Backend{backend}
  Backend --> Local[Local OpenAI-compatible VLM]
  Backend --> Remote[Zhipu/Qwen/OpenAI-compatible VLM]
  Backend --> ShowUI[ShowUI grounding]
  Local --> Parse[相对坐标/文本摘要解析]
  Remote --> Parse
  ShowUI --> Parse
  Parse --> Response[VisionResponse + evidence]
  Response --> Web[gui-web 视觉窗口]
  Response --> CU[computer-use 点击确认]
```

## 迁移摘要

- 本地/远端 VLM、多模态请求、ShowUI grounding、视觉坐标解析和截图证据。
- 本地视觉栈已围绕 UI-DETR、ShowUI、Qwen/Gemma 等资源做多轮评估；8GB 显存限制要求本地资源按需拉起。
- 2026-06-08 推进了 agnes 理解层、误触发修复、视觉会话可配和实时视觉理解 API。
- 视觉语音实时链路已有大量验收截图与 recorder 证据，仍需避免“视觉理解请求误点桌面”。
