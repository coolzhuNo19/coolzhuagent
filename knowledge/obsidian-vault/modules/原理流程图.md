# modules 聚合原理流程图

## 原理流程图

```mermaid
flowchart LR
  GUI[gui-web] --> Core[core-runtime]
  Desktop[gui-desktop] --> GUI
  Core --> LLM[llm-adapter]
  Core --> Tooling[tooling]
  Tooling --> CU[computer-use]
  CU --> Vision[vision]
  Vision --> GUI
  Core --> Diag[diagnostics]
```

## 迁移摘要

- `modules` 是一级目录，下面每个二级模块目录都有五类文档。
- 模块间依赖按“GUI 入口 → Core 编排 → Provider/Tool/Vision/Input/Diagnostics”收敛。
