# Computer Use 原理流程图

## 原理流程图

```mermaid
flowchart TD
  Intent[用户/LLM 操作意图] --> Plan[gui-web action-plan/profile]
  Plan --> Locate[vision GroundingRouter]
  Locate --> Anchor[相对/语义锚点]
  Anchor --> Pixel[物理像素/DPI 映射]
  Pixel --> Gate[execute=false 默认 + 审批]
  Gate --> Input[sendinput/interception 输入后端]
  Input --> Verify[后置截图/diff/视觉确认]
  Verify --> Audit[computer-use audit]
```

## 迁移摘要

- 桌面操作闭环、分辨率矩阵、语义锚点、物理坐标映射、鼠标键盘输入和输入后端预检。
- 精准点击根治方案确认单 VLM 不可靠，系统控件优先走 UIA，内容区目标再走本地/远端 VLM。
- 已形成 profile/closed-loop/safe-click-test 等 Web 侧证据链；后续重点是更多真实应用矩阵和审计完整性。
- 2026-06-19 有 Computer Use 插件启动失败修复日志，需注意插件/后端路径与 MCP worker 并行改动。
