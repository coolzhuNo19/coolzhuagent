# 2026-05-05 GUI WebView 与富媒体交互修复方案

## 背景

桌宠双击会显示/隐藏 Tauri WebView 控制台，该控制台加载的是同一套 Web GUI 页面。但当前 WebView 与浏览器打开页面存在局部字号和内容显示差异；同时对话回复区域的整条消息点击选中逻辑会抢占富文本链接、图片和视频控件的点击。

## 需求拆分

| REQ-ID | 范围 | 目标 |
| --- | --- | --- |
| REQ-WEB-UI-002 | WebView/浏览器一致性 | 固定基础字号、文本缩放和卡片内部布局，降低 WebView 与浏览器差异 |
| REQ-WEB-UI-003 | 三合一卡片 | 去除调试感字段，保留会话、Provider、模型、Key/记忆状态和操作按钮 |
| REQ-WEB-UI-004 | 工程目录 | 内容多时卡片内部滚动，避免挤压或裁切 |
| REQ-WEB-VIS-003 | 内视觉 | 显示最新截图缩略图，路径只作为 tooltip/元数据 |
| REQ-WEB-MEDIA-004 | 富媒体消息 | 链接、图片、视频可点击/播放；消息选中转发改为只在非交互区域触发 |

## 2026-05-05 追加细化项

| 项 | 处理方式 |
| --- | --- |
| 三合一卡片仍显示 `[L1]chat`、`[L2]decision` | 移除主卡片内 memory beads 列表，后续记忆管理放到专用卡片或二级面板 |
| 工程目录路径遮挡 | 工程目录不再显示分支和变更，只保留路径与目录树 |
| 滚动条样式 | 工程目录、三合一卡片等新增滚动条统一使用对话回复同款金色滚动条 |
| 内视觉缩略图空间不足 | 内视觉卡片改为 flex column，按钮固定底部，按钮上方全部用于截图缩略图 |
| 富文本与选中冲突验证 | 给出手动交互测试：链接/图片/视频点击不选中消息，点击非交互正文区域才选中消息 |
| 普通链接/媒体链接重复显示 | 普通链接只在正文显示一次；图片/视频 URL 从正文去重，仅在附件区显示预览 |

## 实施方案

### 字体和布局一致性

- 在 CSS 根层固定 `font-size: 16px`，关闭 WebKit 文本自动放大。
- 给三合一卡片内部增加统一 `font-size` 和 `line-height`。
- 三合一卡片改为 `overflow: auto`，内容多时卡片内滚动。
- 工程目录卡片使用 flex column，工程树列表独立滚动。

### 三合一卡片字段收敛

- 去除页面上的 `超时` 字段。
- 保留 `当前`、`Provider`、`模型`、`Key`、`记忆`、`会话`。
- `Key` 只显示状态或引用名，不显示明文。

### 内视觉缩略图

- 后端 `CaptureMetadata` 增加可安全访问的 `preview_url`。
- 新增静态文件路由 `/api/capture/latest/image`，只返回默认最新截图文件。
- 前端 `setVisionPreview` 负责设置缩略图背景和 tooltip。
- 截图不存在时显示占位图标/文案。

### 富媒体消息交互

- 消息选中只在非交互区域触发。
- 点击 `a`、`button`、`input`、`select`、`textarea`、`video`、`audio`、图片预览、附件 chip 时不切换选中。
- 图片附件直接显示缩略图。
- 视频附件直接显示可播放控件，并保留外链 chip。
- 普通 URL 不生成附件，避免正文和附件区重复显示。
- 图片/视频 URL 正文不再重复显示，统一由附件区承载预览和打开入口。
- 图片识别兼容 `.png/.jpg` 后缀和 `/image/png` 这类无扩展名地址。
- 消息正文支持安全的轻量 Markdown：链接、图片、视频链接、粗体、行内代码、换行。

## 验收标准

| 项 | 验收方式 |
| --- | --- |
| WebView 字体 | Tauri 控制台和浏览器页面三合一卡片字号接近，无明显放大/缩小 |
| 三合一卡片 | 不显示调试感的 `超时` 字段，内容不溢出卡片 |
| 工程目录 | 文件较多时工程树在卡片内滚动 |
| 内视觉 | 点击采集后卡片显示截图缩略图，路径只在 tooltip 可见 |
| 富媒体 | 图片缩略图可打开，视频可播放，链接可点击；点击这些控件不会选中消息 |
| 转发选择 | 点击消息空白/正文非链接区域仍可选中或取消选中 |
| 三合一卡片 | 不显示 `[L1]chat`、`[L2]decision` 等 beads 调试列表 |

## 风险

| 风险 | 缓解 |
| --- | --- |
| 轻量 Markdown 解析过度复杂 | 只支持白名单语法，不执行 HTML |
| 本地文件直接暴露 | 只允许固定最新截图路由，不开放任意路径 |
| 视频外链不可播放 | 保留外链 chip，播放失败仍可打开链接 |
