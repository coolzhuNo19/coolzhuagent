## GUI Web 空间预留建议

以 `1440x900` 作为桌面端设计基准，最低兼容 `1280x760`。整体采用三栏加底部输入栏：

| 区域 | 建议尺寸 | 用途 | 显示策略 |
| --- | --- | --- | --- |
| 顶部状态栏 | 高 `64-78px` | 标题、窗口控制、全局状态 | 固定高度，标题居中 |
| 左侧控制栏 | 宽 `270-300px` | 总览、工程目录、配置、会话、Agent 状态 | 卡片纵向滚动，重要入口靠上 |
| 中心视觉品牌区 | 高 `210-260px` | COOLZHU CODE Logo、背景图、主题氛围 | 只展示品牌，不放可滚动内容 |
| 中心对话区 | 高 `360-430px` | 对话回复、推理过程、任务清单 | 独立滚动，至少显示 30 行 |
| 底部输入区 | 高 `88-110px` | 文本、语音、朗读、框选监控、发送目标 | 固定底部，输入框横向占满 |
| 右侧视觉/工具栏 | 宽 `290-330px` | 内视觉、外视觉、工具调用、测试实验室 | 每张卡片内部滚动，避免页面整体溢出 |

移动或低宽度窗口建议折叠为：

- 左侧栏改为抽屉。
- 右侧栏改为 Tab。
- 中央对话区保留优先级最高。
- 品牌区高度压缩但不遮挡 Logo。

## 对《非多模态页面 UI 开发实施规范细则》的评估

原文档的核心策略是正确的：通过设计令牌、受保护视觉区域、Agent 行为约束、Pagespec/快照验证和 Figma 本地结构化数据，降低无视觉模型 Code Agent 误改 UI 的风险。

建议补充以下工程化条款：

- 增加 `visual-contract.json`：声明关键区域的 DOM selector、边界盒、z-index、允许误差和禁止修改属性。
- 增加资产指纹校验：背景图、Logo、icon sheet 使用 hash 记录，提交前检查 hash 是否变化。
- 增加响应式断点基线：至少保留 `1280x760`、`1440x900`、`1920x1080` 三组截图回归。
- 增加动画降噪机制：截图前统一关闭随机动画、时间、闪烁光效，避免误报。
- 增加 Playwright 截图回归：Pagespec 负责 DOM/CSS 结构差异，Playwright 负责真实渲染截图差异。
- 增加人工确认标签：涉及品牌区、背景、复杂视觉层级的变更必须标记 `manual-visual-confirmation-required`。
- 增加 Agent 修改白名单：只允许修改当前任务授权的组件路径，禁止跨区重排。
- 增加 UI 资源切图规范：icon sheet 必须保留透明背景、统一网格、统一安全边距和命名映射表。
