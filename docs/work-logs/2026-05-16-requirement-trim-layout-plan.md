# 2026-05-16 需求裁剪与 Web GUI 布局重构规划

## 背景

根据最新需求确认，本轮先冻结安装包、加密和完整性校验相关实现，删除外视觉与双视觉模型常驻方向，收敛桌宠和语音能力边界，并将后续主线重心转向 Web GUI 16:9 多窗口重构。

## 需求管理更新

- 新增状态定义：`冻结`，用于表示需求保留历史方案但当前不实现。
- 将安装包、资源加密、完整性校验、可迁移安装等 `REQ-PACK-001~013` 统一调整为冻结。
- 删除外视觉活跃需求池，不再保留外视觉独立功能项。
- 内视觉收敛为 grounding/computer-use 相关能力与云端视觉模型识图，不保留双视觉模型常驻、ShowUI 生命周期托管、持续监控和关键词触发。
- 桌宠当前功能够用，不再新增桌宠需求；语音监控和唤醒词不保留，仅保留 TTS/STT。
- 工具权限要求收敛为：键鼠操作支持按时间授权，workspace 外文件操作需授权，workspace 内 config 与关键数据库需强制授权。
- 新增 P0 需求 `REQ-WEB-UI-010`：Web GUI 16:9 多窗口重构。

## 布局方案文档

新增 `docs/ui-layout-redesign-plan-2026-05-16.md`，记录初版前端布局方案：

- 目标分辨率 1920x1080，16:9。
- 上区高度控制在 20%~30%，默认锁定为 24%，用于 Logo、Agent 总览卡片、任务卡片。
- 下区高度控制在 70%~80%，默认锁定为 76%，作为可复用多窗口工作台，优先保证下部分可用空间。
- 左侧标题栏支持双击折叠/展开，一个窗口展开时其它窗口自动折叠。
- 所有窗口折叠后，下部分展开区域可用于显示马里奥风格 FC 像素小人办公室 3D 动画状态场景。
- 初始窗口规划：工程目录、设置、聊天室、浏览器、多媒体播放器、终端、任务/授权、记忆/知识、视觉实验室、诊断日志。
- 布局比例修正为上区 20%~30%、下区 70%~80%，默认 24% / 76%，先锁定区域布局再进入前端实现。
- 补充当前布局资产清单：折叠窗口图标、窗口框组件、通用表单/按钮组件、Logo 背景、3D 状态场景背景、日志/诊断窗口背景纹理。

## 当前后端缺口

- 待交互确认项：`REQ-WEB-CHAT-007`、`REQ-LLM-005`、`REQ-DESK-PET-003`。
- 工程目录窗口需要文件读取、保存草稿、二进制保护、大文件分页、diff view API。
- 设置窗口需要统一配置聚合接口，覆盖会话、provider、模型、工具、测试、TTS/STT、视觉配置。
- 浏览器窗口缺少会话、导航、搜索、截图和自动化桥接接口。
- 多媒体播放器缺少媒体库、播放列表、元数据、最近播放和播放队列。
- 终端窗口缺少交互式 PTY/WebSocket 终端，需要接入现有工具授权和审计链路。
- 3D 状态场景缺少统一 Agent 活动流接口，可先聚合现有 state、pet、tool events、chat SSE。
