## 背景

多 Agent 协同需求需要先让聊天室知道“还有哪些 peer agent 可协作”。本轮只实现低风险 D1：roster DTO 与查询端点，不改 LLM prompt、不投递 handoff、不改前端任务链。

## 代码变更

- `modules/gui-web/packages/web-console/src/main.rs`
  - 新增路由：`GET /api/chat/rooms/{room_id}/roster?me=<session_id>`
  - 新增 DTO：
    - `ChatRosterQuery`
    - `ChatRosterResponse`
    - `ChatRosterMemberDto`
  - 新增纯函数 `chat_room_roster_from_state(state, room_id, me)`：
    - 校验聊天室存在，不存在返回 404。
    - 从当前 `PersistedSessionState.sessions` 构造成员列表。
    - `me` 存在时排除 self，用于 agent 视角下列出 peers。
    - 返回 `active`、`available`、`model_type`、provider/model/display_name 等字段。
