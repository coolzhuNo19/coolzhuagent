## 技术决策

- 安装器主线：NSIS。
- 授权主线：在线激活服务签发 license token。
- 机器绑定：采集稳定硬件/系统字段后本地 hash，服务端只保存 hash 与设备槽位状态，避免上传原始硬件 ID。
- 防多设备复用：服务端维护 active device slots，超额时引导解绑、迁移或扩容。
- 资源保护：以提高篡改成本和完整性校验为目标，不承诺绝对不可破解，不采用高风险侵入式反调试方案。

## 风险与待确认

- 授权服务需要新增后端/API 设计，后续实现前需确认账号体系、授权码来源、设备槽位数量和解绑流程。
- 机器指纹需要在稳定性与隐私之间取平衡，后续实现应避免上传原始硬件 ID，并提供误判换机的人工恢复路径。
- WebView2、模型资源包、GPU/麦克风/摄像头等安装态验证需要真实 Windows 测试机或虚拟机。
- 加密资源镜像只能提高破解成本，不能作为唯一安全边界；关键权益仍应由服务端签发和校验。
