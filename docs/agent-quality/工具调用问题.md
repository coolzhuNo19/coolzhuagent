## 2026-06-26：2D→3D 技术路线成熟度

### 推荐路线

1. **高质量角色资产生成**：Hunyuan3D-2.1 或 TRELLIS/TRELLIS.2。
2. **轻量 smoke/本机快速链路**：TripoSR 或类似单图到 mesh 模型。
3. **Agent 接入与后处理**：Blender 官方 MCP Server 或 BlenderMCP，让 Agent 控制 Blender 导入、检查、渲染、导出。
4. **游戏可用化**：进入 Blender 后仍需要重拓扑、材质整理、骨骼绑定与动作验证；AI 直接生成 UE5 可用动画角色还不稳定。

### 风险

- Hunyuan3D/TRELLIS 权重通常较大；用户当前 RTX 3070 Ti Laptop 8GB 显存适合先 smoke，不适合直接承诺本地高质量完整生成。
- 若下载速度慢或权重大，应让用户手动下载，并告知下载地址和放置路径。
