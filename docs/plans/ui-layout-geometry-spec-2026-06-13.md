# COOLZHU CODE UI 布局坐标契约

> 日期：2026-06-13  
> 基准画布：1920 × 1080  
> 宽高比：16:9  
> 目的：先固定整体区域，再填充窗口内容，禁止独立区域随视口拉伸。

## 1. 总体规则

1. `.shell.ui-redesign` 永远保持 16:9，只允许整张画布等比缩放。
2. 视口不是 16:9 时，多余区域由 `body` 的延展场景背景承接，不改变内部坐标。
3. 页面区域位置以 1920 × 1080 为唯一设计基准，CSS 使用对应百分比锚定。
4. 位图只能使用 `object-fit: cover` 或 `object-fit: contain`，禁止 `background-size: 100% 100%`。
5. `COOLZHU CODE` 字样烘焙在王座横幅图片中，不再创建独立文字图层。
6. 窗口内容必须在分配区域内滚动或截断，不得反向撑大父级区域。
7. D 区横向 Window Dock 是唯一窗口导航入口；E 区及各子窗口内禁止重复左侧窗口栏。

## 3. 响应式策略

- 1920 × 1080：1:1 呈现。
- 1280 × 720：整张 1920 × 1080 画布按 2/3 等比呈现。
- 2560 × 1080：核心画布保持 1920 × 1080 等比，左右使用延展场景背景。
- 竖向或窄窗口：核心画布仍保持 16:9，超出视口的内容由宿主窗口缩放处理，不单独压扁中栏。

## 4. 开发顺序

1. 固定 shell、顶部三栏、Dock、工作区和输入条区域。
2. 固定王座横幅素材比例，移除 Logo 文字叠层。
3. 多分辨率截图确认边界、比例和图像无变形。
4. 再继续头像、消息卡、窗口主题和交互动效内容填充。
