# 07 · AI 音频编辑类软件 MCP 预装调试方案

> 类别：数字音频工作站（DAW）/ 音频处理自动化。配合总纲使用。

## 一、类别概述
让 AI 通过 MCP 操作 DAW：建轨、编 MIDI、控制传输/速度、加载设备/效果、混音母带、渲染、分析音频，
"用文字把音乐变成动作"。

## 二、候选 MCP / 软件清单

| 项目 | 软件 | 传输 | 成熟度 | 说明 |
| --- | --- | --- | --- | --- |
| AbletonMCP（`ahujasid` 系）/ `uisato/ableton-mcp-extended` | Ableton Live | stdio | 中-高 | 经 Remote Script + MCP：建轨、MIDI/音频轨、剪辑、传输、速度、加载设备、生成 MIDI |
| `xiaolaa2/ableton-copilot-mcp` | Ableton Live | stdio | 中 | 基于 ableton-js，实时控制 Arrangement |
| `bonfire-audio/reaper-mcp`、`wegitor/reaper-reapy-mcp` | REAPER | stdio | 中-高 | 58 工具：工程/轨/MIDI/FX/混音/母带/渲染/分析，能产出完整混音 |
| 生态聚合 | Logic Pro / Pro Tools / FL Studio / Bitwig；Audacity（分析）+ librosa/FFmpeg | stdio | 中 | 见 ChatForest 评测；Anthropic 已推 Ableton/Splice 连接器 |

## 三、推荐预装组合
- **编曲/现场向**：Ableton Live + AbletonMCP（生态活跃，官方连接器在推）。
- **后期/混音母带向**：REAPER + `reaper-mcp`（58 工具覆盖到母带渲染，性价比高）。
- **纯分析**：Audacity + librosa/FFmpeg（自包 plugin）。

## 四、预装方式（在 coolzhu 落地）
1. 宿主：安装 DAW（Ableton/REAPER），装其 **Remote Script / 脚本桥**（如 ableton-js、reapy）。
2. 运行时：Node（ableton-js）/ Python（reapy）。
3. 注册：`mcp_servers.json` → `command/args` 按实现，`transport: stdio`；DAW 须运行并开启远程脚本端口。
4. 自检：`tools/list` 见 track/midi/transport/fx/render 等工具。

## 五、调试与验收用例
- **只读**：读取当前工程轨道列表 / 播放状态。
- **写入（授权后）**：建一条 MIDI 轨 → 写入一段简单旋律 → 渲染导出（沙箱目录）。

## 六、风险与注意
- DAW 须保持运行且开远程脚本，端口/版本要配置化。
- 写操作改真实工程与音频文件 → 用示例工程，写/渲染走授权。
- 第三方音色/插件依赖（VST）需随宿主预装，缺失会导致加载失败。

## 七、参考来源
- AbletonMCP / `uisato/ableton-mcp-extended` / `xiaolaa2/ableton-copilot-mcp`、`bonfire-audio/reaper-mcp`、`wegitor/reaper-reapy-mcp`；ChatForest 音频 MCP 评测、Sonic Field。

## 接入状态（2026-06-11，已纳入 MCP Host 预装清单）

- **包**：ableton-mcp (PyPI ableton-mcp@1.2.0, ahujasid 官方, 经 python -m uv tool run)
- **连接自检**：connect 16.4s PASS（21 工具）。调用需 Ableton Live + Remote Script，宿主就绪后冒烟 get_session_info
- **工具数**：21
- **工具样例**：get_session_info / get_track_info / create_midi_track / create_clip / add_notes_to_clip / set_tempo / load_instrument_or_effect …
- 用法：`POST /api/mcp/servers/<id>/connect` → `POST /api/mcp/call`。依赖宿主/Key 的条目在 workspace `.coolzhu/mcp_servers.json` 配齐后冒烟。
