# 06 · AI 视频编辑类软件 MCP 预装调试方案

> 类别：非线性剪辑（NLE）自动化。配合总纲使用。

## 一、类别概述
让 AI 通过 MCP 操作剪辑软件：建/载工程、管理时间线/轨道/片段、导入素材、调色、调音、控制播放、跑脚本，
把重复性剪辑工作自动化。

## 二、候选 MCP / 软件清单

| 项目 | 软件 | 传输 | 成熟度 | 说明 |
| --- | --- | --- | --- | --- |
| `samuelgursky/davinci-resolve-mcp` | DaVinci Resolve Studio | stdio | 中-高 | 工程/时间线/片段/Fusion/调色/音频/播放/页面/脚本 全覆盖 |
| `apvlv/davinci-resolve-mcp` | Resolve + Fusion | stdio | 中 | 另一实现，含 Fusion |
| Jumper（getjumper.io） | Premiere / Resolve / Final Cut / Avid | stdio | 中 | **多 NLE** 统一 agent 工作流 |
| `atx-guy/capcut-mcp-server` | CapCut Pro | stdio | 中 | 程序化建/剪视频 |

## 三、推荐预装组合
- **专业首选**：DaVinci Resolve Studio + `samuelgursky/davinci-resolve-mcp`（功能最全，注意需 **Studio 版**才有脚本 API）。
- **多软件统一**：Jumper（一套 agent 覆盖 Premiere/Resolve/FCP/Avid）。
- **轻量/模板向**：CapCut MCP。

## 四、预装方式（在 coolzhu 落地）
1. 宿主：安装 DaVinci Resolve **Studio**（免费版脚本 API 受限）/ 对应 NLE；开启其脚本/外部访问。
2. 运行时：Python（Resolve 脚本走其内置 Python）/ Node。
3. 注册：`mcp_servers.json` → `command/args` 按实现，`transport: stdio`；需设 Resolve 脚本环境变量（`RESOLVE_SCRIPT_API`/`RESOLVE_SCRIPT_LIB`/`PYTHONPATH`）。
4. 自检：`tools/list` 见 project/timeline/clip/media/color 等工具。

## 五、调试与验收用例
- **只读**：列出当前工程的时间线 / 片段清单。
- **写入（授权后）**：新建工程 → 导入一段示例素材 → 加到时间线 → 渲染一小段（沙箱目录）。

## 六、风险与注意
- **Studio 版限制**：DaVinci 免费版脚本 API 不全，预装须确认 Studio。
- 渲染/导出耗时耗算力，导出动作单列确认并落沙箱目录。
- 素材路径、编解码器依赖（FFmpeg）要随宿主预装。

## 七、参考来源
- `samuelgursky/davinci-resolve-mcp`、`apvlv/davinci-resolve-mcp`、Jumper(getjumper.io)、`atx-guy/capcut-mcp-server`。

## 接入状态（2026-06-11，已纳入 MCP Host 预装清单）

- **包**：davinci-resolve-mcp (npm davinci-resolve-mcp@2.45.0)
- **连接自检**：连接失败：包依赖 anyio 未声明（包侧 bug）+ 需 Resolve Studio 脚本环境。预置 enabled=false，宿主+修复后于 workspace 开启

- 用法：`POST /api/mcp/servers/<id>/connect` → `POST /api/mcp/call`。依赖宿主/Key 的条目在 workspace `.coolzhu/mcp_servers.json` 配齐后冒烟。
