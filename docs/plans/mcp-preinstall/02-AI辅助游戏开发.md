# 02 · AI 辅助游戏开发 MCP 预装调试方案

> 类别：游戏引擎自动化（Godot / Unreal / Unity）。配合总纲使用。

## 一、类别概述
让 AI 通过 MCP 控制游戏引擎编辑器：建场景/节点、写脚本、连信号、配材质/动画/光照，
跑工程并读报错；进一步可走"截图→视觉检查→修复"的自动闭环。

## 二、候选 MCP / 软件清单

| 引擎 | 代表项目 | 传输 | 成熟度 | 说明 |
| --- | --- | --- | --- | --- |
| Godot 4 | `Coding-Solo/godot-mcp`、`hi-godot/godot-ai`（~39 工具/120+ ops，一键配 19 客户端）、**godogen**（`htdt/godogen`，Claude Code 技能，自动规划→写码→生成资产→跑引擎→截图检查→修复） | stdio | 中-高 | 开源活跃，含视觉反馈闭环（Gemini Flash 看截图查 z-fighting/缺贴图） |
| Unreal 5 | `chongdashu` UE MCP、`ChiR24/Unreal_mcp`（C++ Automation Bridge）、VibeUE（编辑器内 AI 聊天）、`game-dev-mcp`（Remote Control API，200+ 工具） | stdio | 中-高 | 经 C++ 插件/Remote Control 控制 actor/material/blueprint/level |
| Unity | Unity MCP（C# 服务，连编辑器与 LLM）、Yamu（编译/测试，edit-compile-debug 闭环） | stdio | 中 | 编辑器实时自动化 |

## 三、推荐预装组合
- **轻量首选**：Godot 4 + `godot-mcp`/`godot-ai`；追求"一句话出可玩 demo"可叠加 **godogen** 技能管线。
- **3A/重度**：Unreal 5 + `game-dev-mcp`（Remote Control API）或 C++ Automation Bridge 实现。
- **Unity 工作流**：Unity MCP + Yamu（自动编译测试）。

## 四、预装方式（在 coolzhu 落地）
1. 宿主：安装对应引擎（Godot 4.x / UE5 / Unity），装各自 MCP 插件并开启编辑器内服务/Remote Control。
2. 运行时：多为 Node（`npx`）或引擎内置；godogen 走 Claude Code 技能 + 引擎 CLI。
3. 注册：`mcp_servers.json` 配 `command/args/transport=stdio`；引擎须保持编辑器开启或可被 CLI 拉起。
4. 自检：`tools/list` 见 scene/node/script/run/material 等工具。

## 五、调试与验收用例
- **只读**：读取当前场景树 / 工程错误日志。
- **写入（授权后）**：新建场景 + 一个节点 + 绑定脚本 → 运行 → 截图。
- **闭环（进阶）**：godogen 式"给一句描述→生成可运行最小 demo→截图自查"。

## 六、风险与注意
- 引擎版本与插件强绑定，预装固定版本；UE 编译耗时大，需资源预算。
- 自动化会改真实工程 → 用示例工程 + 版本控制；写操作走授权。
- 截图视觉检查需视觉模型额度；闭环失败要有重试上限（呼应 Goal 失败回退）。

## 七、参考来源
- Godot：`Coding-Solo/godot-mcp`、`hi-godot/godot-ai`、`htdt/godogen`；Unreal：`ChiR24/Unreal_mcp`、`chongdashu` UE MCP、VibeUE、`game-dev-mcp`；Unity MCP、Yamu。

## 八、接入状态（2026-06-09）

- **已接入 MCP Host 预装清单**：`godot-mcp`（npm `godot-mcp@0.1.0`，`cmd /c npx -y godot-mcp`，enabled=true）。
- **连接自检 PASS**：initialize + tools/list → 14 工具：
  `launch_editor / run_project / get_debug_output / stop_project / get_godot_version / list_projects /
   get_project_info / create_scene / add_node / load_sprite / export_mesh_library / save_scene / get_uid / update_project_uids`。
- **冒烟**：`get_godot_version` 如实返回"未找到 C:\Program Files\Godot\Godot.exe + 解决建议"
  ——调用链路通；本机未装引擎，引擎类工具待装 Godot 4.x 后复测（创建场景→加节点→运行→截图 验收用例不变）。
- 用法：`POST /api/mcp/servers/godot-mcp/connect` → `POST /api/mcp/call {"server_id":"godot-mcp","tool":"...","arguments":{...}}`。
