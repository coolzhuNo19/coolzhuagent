# 08 · AI 视频生成类软件 MCP 预装调试方案

> 类别：文/图生视频（生成式）。配合总纲使用。

## 一、类别概述
让 AI 通过 MCP 调用视频生成模型：文生视频、图生视频、续写/remix、跟踪任务进度、下载保存、拼接淡入淡出。
本类多为**远程 HTTP MCP + 厂商 API Key**，受额度与可用性限制。

## 二、候选 MCP / 软件清单

| 项目 | 后端模型 | 传输 | 成熟度 | 说明 |
| --- | --- | --- | --- | --- |
| Runway MCP（官方 `runwayml.com/news/mcp`） | Gen-4.5、Seedance 2.0、Kling 3.0、Nano Banana Pro、GPT Image 2 | HTTP（custom connector） | 中-高 | 官方，多模型；Claude/ChatGPT/Cursor 加自定义连接器即用 |
| `writingmate/sora-2-mcp`、`AceDataCloud/SoraMCP` | OpenAI Sora 2 | stdio/HTTP | 中 | 文生视频 + FFmpeg 合并/淡入；**Sora 2 API 仍受限**，多数人暂跑不通 |
| Video Agent MCP（`h2a-dev`） | Kling 2.1、Hailuo 02 等 | stdio | 中 | 图生视频 + 音乐/语音生成 + 视频拼装 |
| ComfyUI（开源 Wan 2.1 等） | 本地/自建 | stdio（自包） | 中 | 开源视频模型主要生态；**无官方 MCP**，需自写 server 或用 Replicate/DashScope 包装 |

## 三、推荐预装组合
- **省心首选**：Runway MCP（官方 HTTP 连接器，模型多、稳定）。
- **本地/开源向**：ComfyUI + 自包 MCP 包装（Wan 等，无需厂商额度，但要 GPU）。
- **多能力拼装**：Video Agent MCP（生成 + 配乐 + 拼装一体）。

## 四、预装方式（在 coolzhu 落地）
1. **HTTP 类（Runway/Sora）**：取得厂商 API Key；走总纲**路径 A 的 HTTP MCP** 或自定义连接器 URL。
2. **stdio 类（Video Agent/ComfyUI 包装）**：Node/Python 运行时；ComfyUI 需本地 GPU + 模型权重。
3. 注册：`mcp_servers.json` → HTTP 填 `url + 鉴权 header`；stdio 填 `command/args`；Key 走 `env`。
4. 自检：`tools/list` 见 generate/status/list/download 等；先跑一次**最短时长**生成验证链路。

## 五、调试与验收用例
- **链路**：提交一段 3–5s 文生视频任务 → 轮询进度 → 下载到沙箱 → FFmpeg 合并校验。
- **图生视频**：给一张图 + 运动提示，生成短片段。

## 六、风险与注意
- **API Key/额度**：Key 走 env 不外传不入 query；生成**按量计费**，预装阶段限时长/分辨率控成本。
- **可用性**：Sora 2 API 访问受限，预装前确认账号权限，否则以 Runway/开源替代。
- ComfyUI 本地生成吃 GPU 显存与磁盘（模型权重大），需资源预算。
- 生成内容合规：版权/深伪风险，输出留水印/审阅。

## 七、参考来源
- Runway MCP（`runwayml.com/news/mcp`）、`writingmate/sora-2-mcp`、`AceDataCloud/SoraMCP`、Video Agent MCP（`h2a-dev`）、ComfyUI/Wan 2.1 生态。

## 接入状态（2026-06-11，已纳入 MCP Host 预装清单）

- **包**：minimax-mcp (PyPI minimax-mcp@0.0.18, 官方, 经 python -m uv tool run)
- **连接自检**：连接如实报错 MINIMAX_API_KEY environment variable is required——依赖外部 API Key（设计预期）。在 workspace mcp_servers.json 的 env 填 MINIMAX_API_KEY 后即可连接（勿硬编码）

- 用法：`POST /api/mcp/servers/<id>/connect` → `POST /api/mcp/call`。依赖宿主/Key 的条目在 workspace `.coolzhu/mcp_servers.json` 配齐后冒烟。
