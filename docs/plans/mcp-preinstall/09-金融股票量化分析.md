# 09 · 金融股票量化分析类软件 MCP 预装调试方案

> 类别：行情/财报数据 + 量化回测/交易。配合总纲使用。
> ⚠️ 合规红线：本项目**不执行下单/转账/交易**，不提供个性化投资建议。MCP 仅用于**数据获取与分析**。

## 一、类别概述
让 AI 通过 MCP 拉取实时/历史行情、财报、估值、持仓、并购等数据并做分析；量化平台可做**回测**。
研究表明 LLM 应作"编排者"调用权威数据源，而非自己当数据来源（QuantMCP 思路）。

## 二、候选 MCP / 软件清单

| 项目 | 类型 | 传输 | 成熟度 | 说明 |
| --- | --- | --- | --- | --- |
| Alpha Vantage MCP（官方 `mcp.alphavantage.co`） | 行情数据 | HTTP | 高 | 实时/历史股票数据，官方，Claude/Cursor/VS Code 直连 |
| Financial Modeling Prep（FMP）MCP | 基本面/行情 | HTTP | 高 | 7 万+ 数据点直供 agent |
| EODHD MCP | 行情/财报 | HTTP | 高 | 77 只读工具 + 100+ 文档资源 + 3 prompt 模板 |
| `financial-datasets/mcp-server` | 股票数据 API | stdio/HTTP | 中-高 | 官方 Financial Datasets |
| FactSet MCP | 机构级数据 | HTTP | 高（商用） | Fundamentals/Estimates/Ownership/M&A/供应链 |
| QuantConnect MCP | 量化回测/实盘平台 | HTTP | 中-高 | 回测 + （平台侧）实盘能力 |
| FinancialData.Net MCP | 行情数据 | HTTP | 中 | 股市与财务数据 |

## 三、推荐预装组合
- **数据分析首选（免费可起步）**：Alpha Vantage MCP + FMP MCP（覆盖行情 + 基本面）。
- **财报/事件深度**：EODHD MCP（工具与文档最全）。
- **量化回测**：QuantConnect MCP（**仅回测/研究**，实盘下单不在本项目范围）。

## 四、预装方式（在 coolzhu 落地）
1. 取得各数据源 API Key（Alpha Vantage/FMP/EODHD 等）。
2. 运行时：HTTP 类走总纲**路径 A 的 HTTP MCP**/自定义连接器；stdio 类用 Node/Python。
3. 注册：`mcp_servers.json` → HTTP 填 `url + 鉴权`；Key 一律走 `env`，不入 query。
4. 自检：`tools/list` 见 quote/historical/fundamentals/search 等；拉一只示例股票实时报价验证。

## 五、调试与验收用例
- **数据**：查某股票实时报价 + 近 30 日 K 线 + 最新财报摘要。
- **分析**：用拉到的数据算一个均线/波动率指标并出图表（只读分析，不下单）。
- **回测（QuantConnect）**：跑一个示例策略回测，读回测指标。

## 六、风险与注意（重点）
- **绝不下单/转账/交易**，不做个性化投资建议（与安全基线一致）；如用户问，明确"非持牌、仅数据分析"。
- API Key 走 env/本地配置，不硬编码、不入 URL query、不外传。
- 数据有延迟/口径差异，分析结论需标注数据源与时间；免费额度有频控。
- 回测 ≠ 实盘，过拟合风险需提示。

## 七、参考来源
- Alpha Vantage MCP（`mcp.alphavantage.co`）、FMP MCP、EODHD MCP、`financial-datasets/mcp-server`、FactSet MCP、QuantConnect MCP、FinancialData.Net；QuantMCP（arXiv 2506.06622）。
