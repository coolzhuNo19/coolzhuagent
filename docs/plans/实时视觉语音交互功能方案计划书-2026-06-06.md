# 实时视觉语音交互功能 — 方案计划书

> 日期：2026-06-06
> 适用：coolzhu code agent（web-console + tauri-shell）
> 验收场景：①语音控制台（实时指挥模型对桌面软件做视觉操作）；②实时交互式教学（如英语互动教学）

## 一、现有基座（代码事实，可复用）

| 能力 | 落点 | 说明 |
| --- | --- | --- |
| STT 分段录音 | `POST /api/audio/stt/{start,stop,data}`（main.rs:583-585） | openai-whisper（`audio.rs:transcribe_file*` / `transcribe_python`），模型置于 `models/`（whisper `base.pt`） |
| 实时音频管道 | `POST /api/audio/realtime/{start,stop}`、`GET .../status`（590-592）；`transcribe_realtime_final_audio_segment`（main.rs:30734） | 已有实时录音→分段转写脚手架 |
| TTS 合成 | `POST /api/audio/tts/speak`、`GET /api/audio/tts/files/{id}`、`GET /api/audio/voices`（586-589） | piper（`synthesize_piper`，huayan 中文模型 + 本地音调偏移）；可选 IndexTTS（`synthesize_indextts_http`，音色克隆） |
| 内置音色 | `audio.rs:builtin_voices`（1478） | 成人男/女/中性/孩童（已落地） |
| 自动朗读门控 | `app.js:maybeAutoSpeakRealtimeReply` | 大模型回复自动 TTS（语音输入触发） |
| 视觉定位 | `POST /api/vision/{find-target,locate,locate/verify}`（684-715） | 截图 + 视觉模型 + 坐标解析（vision 模块 / UIA） |
| 实时视觉 | `POST /api/vision/realtime/stop`（710，含对应 start） | 实时截图流脚手架 |
| 桌面执行 | `POST /api/computer-use/{action-plan,closed-loop,profile}`（736-747） | 鼠标键盘、安全点击、分辨率映射；闭环执行 |
| 桌面视觉外壳 | ShowUI 服务（main.rs:`start_showui_service` 1924） | 视觉操作外壳进程 |
| 权限闸 | 三档授权（workspace 内 / workspace 外指定目录 / full access） | 已落地，可作为危险操作的授权来源 |

**判断**：实时语音（STT/TTS/realtime）+ 实时视觉（screenshot/locate）+ 桌面执行（closed-loop）三条链路**均已有独立脚手架**，本方案核心是**把三者串成低延迟闭环**并补两类场景的对话/教学逻辑，而非从零造轮子。

## 二、总体架构：实时多模态闭环

```
麦克风 ─VAD─▶ 流式STT ─▶ 意图/对话(LLM) ─┬─▶ 视觉grounding(截图+locate) ─▶ 安全执行(closed-loop) ─┐
   ▲                                      └─▶ 对话/教学应答 ────────────────────────────────────────┘
   │                                                                                                  ▼
   └──────────────────────────────── TTS 语音反馈(多音色) ◀── 结果/话术 ◀───────────────────────────┘
```

- **事件总线**：前端以 SSE/WebSocket 接收 `partial_transcript` / `final_transcript` / `assistant_text` / `tts_chunk` / `action_step` / `screenshot` 事件，驱动实时面板。
- **打断（barge-in）**：用户开口即暂停当前 TTS，丢弃在途应答（教学/控制台都需要）。
- **截图节流**：仅在"需要看屏"时截图（locate 前），或固定 1–2 fps 限流，避免刷屏与算力浪费。

## 三、场景一详设：语音控制台（桌面视觉操作）

**目标**：用户口述"打开记事本并输入今天的待办"，模型实时看屏、定位、点击、输入并语音回报。

**链路**：
1. 流式 STT 得到 `final_transcript`。
2. LLM 解析为**动作意图**（沿用 `/api/computer-use/action-plan`），产出 step 序列。
3. 每步：`/api/vision/find-target` 或 `locate` 做视觉 grounding → `locate/verify` 校验 → `/api/computer-use/closed-loop` 执行（带安全点击/分辨率映射）。
4. 危险动作（点击系统/安全设置、删除、提交表单等）**走三档授权二次确认**；默认仅允许 workspace 内/受控动作。
5. 每步完成 TTS 语音回报，失败可口头纠错（"点错了，点左边那个"）→ 重新 grounding。

**关键点**：
- 低延迟流式 STT（分段 + 端点检测），目标"说完→开始执行" < 1.5s。
- 视觉 grounding 准确率：locate + verify 双段降低误点。
- 误操作防护：执行前高亮目标 + 可口头/快捷键中止（kill-switch）。
- 与现有 Goal/closed-loop 对齐，复用 profile（分辨率映射）。

**验收**：连续 5 条语音指令，端到端成功完成 ≥4 条，危险动作 100% 走授权确认，全程可语音中止。

## 四、场景二详设：实时交互式教学（英语）

**目标**：全/半双工英语对话，角色音色，可看屏/看教材给反馈（如纠正发音、讲解屏幕上的题目）。

**链路**：
1. 双向语音对话：STT → 教学 LLM（带教学剧本/角色 prompt）→ TTS（角色音色，复用 builtin_voices 或 IndexTTS 克隆）。
2. 视觉辅助（可选）：截图理解学生屏幕上的教材/题目（`/api/vision/locate` + 视觉模型 OCR/理解）。
3. 教学状态机：话题 → 提问 → 学生作答 → 评测/纠错 → 反馈 → 下一轮；记录回合与得分。
4. 发音/语法反馈：基于 STT 文本做语法纠错；发音评测为可选增强（需音素对齐，二期）。

**关键点**：
- 低延迟 + barge-in（学生随时插话）。
- 角色化音色（孩童/成人男女）+ 语速可调（已支持 length_scale + 音调偏移）。
- 教学剧本可配置（JSON 剧本：场景、目标句型、评分维度）。
- 多轮上下文与进度持久化（沿用会话存储）。

**验收**：一段 ≥5 轮的英语对话，TTS 角色音色稳定，能就学生答句给出至少 1 处语法/用词反馈，支持中途打断改话题。

## 五、关键技术难点与对策

| 难点 | 对策 |
| --- | --- |
| 端到端延迟 | 流式 STT 分段 + TTS 分句流式播放（首句优先）；LLM 走快速首 token |
| 打断/纠错 | 前端 VAD 检测开口 → 立即停 TTS + 取消在途请求；服务端幂等取消（已有 `transcribe_file_with_cancel`） |
| 视觉误点 | locate→verify 双段 + 执行前目标高亮 + kill-switch |
| 安全 | 危险动作强制三档授权二次确认；麦克风/截屏明确开关与状态指示 |
| 截图开销 | 按需截图 / 限流；只截活动窗口区域 |
| 中文 Windows 编码 | 子进程输出统一 `decode_console_output`（GB18030 回退），避免乱码 |

## 六、分阶段里程碑

- **M1（打通闭环）**：realtime STT → LLM → TTS 全双工骨架 + 事件总线 + barge-in。
- **M2（场景一）**：语音 → action-plan → locate/verify → closed-loop，含三档授权与 kill-switch。
- **M3（场景二）**：教学状态机 + 角色音色 + 多轮持久化 + 基础语法反馈。
- **M4（增强）**：视觉辅助教学（看教材）、发音评测、延迟优化、可观测指标面板。

## 七、风险与安全

- **隐私**：麦克风常听 + 屏幕截取属敏感；需显著开关、运行指示灯、本地处理优先、不外传。
- **误操作**：视觉操作有现实副作用；默认最小权限 + 授权确认 + 可中止 + 操作日志。
- **稳定性**：实时管道长跑需重连/超时/资源回收（音频句柄、临时音频文件清理）。

## 八、验收标准（汇总）

1. 语音控制台：≥4/5 指令端到端成功；危险动作 100% 授权；全程可语音/快捷键中止。
2. 教学：≥5 轮英语对话，角色音色稳定，≥1 处有效语言反馈，支持打断。
3. 端到端首响应延迟 < 1.5s（控制台）/ < 1.2s（教学首句）。
4. 全程无中文乱码；麦克风/截屏有明确状态指示。
